# CLAUDE.md

## Regras de commit (permanentes)

- Claude nunca deve ser adicionado como coautor de commits.
- Anthropic nunca deve ser adicionada como coautora de commits.
- Nunca adicionar a linha `Co-Authored-By: Claude` (ou qualquer variação com Claude/Anthropic) em mensagens de commit.
- Nunca adicionar `Generated by Claude` ou `Generated with Claude`.
- Nunca adicionar mensagens indicando que o código foi gerado por IA.
- Nunca modificar `git config user.name`.
- Nunca modificar `git config user.email`.
- Todos os commits devem usar exclusivamente a identidade Git já configurada pelo desenvolvedor (autor = usuário, não Claude/Anthropic).
